# Custom ESP Watch
This project is a custom watch I have been developing for about a month, as of now (11/11/26) I am just starting to assemble the pcbs and order the final parts. This board has many components each serving a specific function for the watch.

# Capabilities
* RTC chip built in
* Rotary encoder for input
* High battery life
* Low battery consumption
* Buzzer for notifications
* Memory lcd to maximize battery life
